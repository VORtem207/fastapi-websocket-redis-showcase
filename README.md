## FastAPI WebSocket Chat + Redis Pub/Sub (Showcase)

Прототип чата с поддержкой масштабирования.
Использовал FastAPI WebSockets и Redis Pub/Sub для распределённой обработки сообщений.

Учебный проект (незавершённый). Использовал для практики:
- WebSocket протокола,
- Redis Pub/Sub,
- управления сессиями.
